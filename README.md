## 🚀 Descripción del Proyecto
Este sitio web es un portafolio profesional interactivo diseñado para presentar mi perfil, mis competencias técnicas en desarrollo frontend y la muestra de los ejercicios prácticos realizados en clase.

El proyecto aplica estándares de maquetación semántica con **HTML5**, diseño responsivo e interactivo mediante **CSS3** y gestión de código con el sistema de control de versiones **Git y GitHub**.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5:** Estructuración del documento mediante etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Hoja de estilos externa, variables CSS (`:root`), maquetación con **Flexbox**, efectos interactivos (`:hover`) y diseño adaptable a dispositivos móviles (**Media Queries**).
* **Git & GitHub Desktop:** Control de versiones con historial de commits progresivos.
* **Phoenix Code:** Entorno de desarrollo para la edición del código fuente.
* **Google Chrome:** Navegador utilizado para visualización y depuración con la consola de desarrollador.
